# Nginx 快速启动

## 背景

开发中经常涉及到基于 Nginx/OpenResty 的测试，且需要做不同的配置，各种比较繁琐。

我们希望达到如下效果：

- 只安装一份 Nginx/OpenResty
- 能够在不同的配置间切换，做不同的测试
- 能够方便地查看日志，最好是控制台，有高亮显示
- 方便启动、停止，方便重新加载配置



## 思路

Nginx/OpenResty 的启动命令，可以通过 `-p`、`-c` 等参数指定配置文件和工作目录，同时可以在前台运行服务。

同时通过 tspin、lnav 等日志工具，查看日志。



## 解决方案

安装一份 Nginx/OpenResty。

生成一份配置和启动脚本，作为模板。然后每次使用的时候，在指定的位置创建副本，基于副本修改配置、启动程序，以实现方便切换配置，快速开始。
