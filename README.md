# 🧩 Nginx / OpenResty 快速启动环境

## 背景

在开发过程中，常常需要基于 **Nginx** 或 **OpenResty** 进行各种配置和功能测试，例如：

* 不同的反向代理、路由规则；
* Lua 模块、接口、缓存逻辑等；
* SSL、负载均衡、API 网关等实验。

这些测试通常存在以下问题：

* 每次都要修改系统级配置；
* 日志路径、端口、缓存文件容易互相影响；
* 启停命令不方便；
* 难以保留和对比多份配置。

我们希望能做到：

* ✅ 只安装一份 Nginx/OpenResty；
* ✅ 快速在不同配置间切换；
* ✅ 控制台可直接查看高亮日志；
* ✅ 启动、停止、重载都方便；
* ✅ 各个测试环境互不影响。

---

## 思路

Nginx/OpenResty 支持通过参数灵活指定运行环境：

* `-p <prefix>` 指定工作目录；
* `-c <conf>` 指定配置文件；
* `-g 'daemon off;'` 前台运行。

这意味着可以让多个测试实例共用同一个可执行文件，但使用不同的配置、日志和工作目录。

再结合 `tspin`、`lnav`、`bat` 等工具，可以轻松地在控制台查看、过滤和高亮日志输出。

---

## 解决方案

1. **系统仅安装一份 Nginx/OpenResty**；
2. **准备一个模板目录**，包含完整的配置文件、mime 类型定义和启动脚本；
3. **通过初始化脚本自动复制模板**，为每次测试生成独立的运行目录；
4. 每个实例拥有独立的 `conf/`、`logs/`、`work/` 等子目录，互不干扰。

---

## 🧰 脚本说明

### 一、初始化脚本：`ngx-quick-init.sh`

#### 用法

```bash
./ngx-quick-init.sh <目标目录>
```

示例：

```bash
./ngx-quick-init.sh demo
```

#### 功能说明

| 功能            | 说明                         |
| ------------- | -------------------------- |
| 📦 **模板复制**   | 将 `template/` 下所有文件复制到目标目录 |
| 🗂️ **结构初始化** | 自动创建 `work/html` 与 `logs`  |
| 🔒 **防误覆盖**   | 若目录存在则终止执行                 |
| ⚙️ **权限调整**   | 自动为 `start.sh` 赋予执行权限      |
| 💬 **操作提示**   | 输出后续启动命令                   |

生成结果示例：

```
demo/
├── conf/
│   ├── ngx.conf
│   └── mime.types
├── work/
│   └── html/
├── logs/
└── start.sh
```

#### 价值与优势

* **配置隔离**：每个测试环境都有独立配置与日志；
* **快速复制**：一键创建全新实验环境；
* **可回溯**：可独立提交至 Git；
* **无侵入性**：不修改系统级配置；
* **可扩展性强**：支持多模板、强制覆盖、端口自增等功能。

> 💡 它就像是一个“轻量级配置容器生成器”：一次配置，多次复用。

---

### 二、启动脚本：`start.sh`

#### 用法

```bash
cd demo
./start.sh
```

#### 功能概要

* 指定独立运行目录与配置文件：

  ```bash
  openresty -p "$WORK_DIR" -c "$CFG_FILE" -g 'daemon off;'
  ```
* 自动解析配置文件中的 `listen` 端口；
* 启动后通过 `curl` 检查服务可用性；
* 若安装了 `bat`，会高亮输出 HTTP 头；
* 若安装了 `tspin`，可流式查看日志输出。

---

## ⚠️ 注意事项

* 当前脚本不会自动检测端口占用；
* 若配置文件中包含多个 `listen` 指令，仅解析第一个；
* `$PROJECT_NAME` 未定义，可补充或移除；
* 可扩展 `--force` 或 `--template` 参数实现更多功能。

## 🔧 推荐配合工具

| 工具                                       | 用途             |
| ---------------------------------------- | -------------- |
| [`tspin`](https://github.com/nvbn/tspin) | 实时日志流高亮        |

| [`lnav`](https://lnav.org/)              | 日志文件浏览与过滤      |
| [`curl`](https://curl.se/)               | 快速检测 HTTP 服务响应 |

---

## ✅ 总结

本方案让 Nginx/OpenResty 的本地测试环境：

* ✅ **像容器一样可复制、可销毁、可回溯**
* ✅ **避免污染系统环境**
* ✅ **支持多实例并行运行**
* ✅ **便于脚本化测试与配置版本管理**
